# 和缓医疗

和缓医疗关注严重疾病患者及其家庭在治疗全过程中的生活质量，通过症状管理、心理支持、照护沟通与家庭陪伴，帮助患者更舒适、更有尊严地面对疾病。

## 核心理念

- 以患者为中心，尊重患者的价值观、目标与选择。
- 重视疼痛、呼吸困难、疲乏、焦虑等身心症状的综合管理。
- 支持家属参与照护决策，降低照护压力与信息焦虑。
- 与原有诊疗团队协作，补充而不是替代疾病治疗。

## 服务内容

- 症状评估与舒缓照护建议
- 治疗目标沟通与共同决策支持
- 心理、社会与灵性层面的关怀
- 家庭照护指导与照护者支持
- 临终关怀与哀伤支持资源衔接

## 适用场景

和缓医疗适用于肿瘤、心衰、慢阻肺、神经退行性疾病、终末期肾病等严重或慢性进展性疾病患者。它可以从确诊早期开始介入，也可以在治疗转换、症状加重或家庭需要更多支持时提供帮助。
